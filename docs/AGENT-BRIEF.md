## 1. Refined product

Car Choice BD is a Japanese reconditioned-car showroom in Rajshahi, Bangladesh (Near BRTA Office, Amchattar, 6203). The website is a sales tool, not a marketplace clone and not a customs calculator.

A visitor should be able to:

1. Trust the showroom in the first screen (dark cinematic video, gold wordmark, short copy).
2. Browse ready stock, open a car, and message WhatsApp with the car already named.
3. Ask the showroom to source a car from Japan (pre-order).
4. Send an auction sheet for a free staff check.
5. Look up a **showroom duty sheet** figure (staff-edited taka, not a live Customs formula and not live stock).
6. See cars already delivered.

Staff should be able to, from `/admin`:

- Publish and edit vehicles.
- Read contact, verify, and pre-order leads.
- Publish delivered-car photos.
- Replace duty-sheet rows.

The visual bar is a premium dark showroom: near-black canvas, frosted glass, one gold accent. Motion is short and mechanical. Phone layout is the primary review surface. Desktop must still work.

Reference for information architecture was `https://gari-import.com.bd`. Do not copy that site’s name, fees, deposits, auction portal, or parts shop. Reference for the duty lookup flow was `https://autovanjp.com/car-duty/`. Do not scrape or paste their paid duty sheet. Car Choice numbers live in an editable sheet.

Domain: `https://www.carchoicebd.com`. Repo: `https://github.com/mahmud076-B/car_choice_bd_test.git` (branch `main`).

## 3. What exists now

Stack: Next.js **16.4.2** (App Router, Turbopack), React 19.3, TypeScript, Tailwind CSS 4, Zod 4, Supabase optional, `lucide-react` icons.

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. Without Supabase env vars the site is in **demo mode**: mock vehicles, leads in `.data/` JSON, admin UI open with no login.

This Next.js is not the older Next you may remember. Before using a new framework API, read the matching guide in `node_modules/next/dist/docs/`. `AGENTS.md` is regenerated by `next dev`. Do not delete that block.

### Type

- Headings: **Outfit** (`--font-outfit`), white, tight tracking on heroes.
- Body and UI: **Plus Jakarta Sans** (`--font-jakarta`).
- Eyebrows: 11–12px, uppercase, tracking ~0.2em, gold.
- Hero headline (current home): about `1.85rem` on a phone, `text-5xl` and up on desktop, line-height ~1.08–1.18.
- Do not add a third font.

### Wordmark

```tsx
<span className="font-extrabold tracking-tight text-white leading-none">
  CAR <span className="text-[#d4af37]">CHOICE</span> BD
</span>
```

Same size, same line, same weight. Header is `text-[15px] sm:text-lg`. Footer is `text-lg`. Logo mark is `/logo.svg`, inverted to white, slight gold drop shadow. Do not put a separate “BD” chip on the emblem.

### Shape and motion

- Public pills and hero CTAs: `rounded-full`.
- Cards: `rounded-2xl` (1rem) or `glass-panel` at 1.5rem.
- Primary button: gold fill, dark text, weight 700.
- Ghost button: white/6 fill, white text, gold border and gold text on hover.
- Open dropdown: one menu at a time, 300ms fade/scale, options stagger ~28ms, selected row gold with a check, chevron rotates. Escape and outside click close it. Picking a value clears later fields and opens the next step.
- Hero rotating words (Ready Stock, Pre-Order, Auction Grade, Delivered): CSS `.hero-word`, 10.6s loop. Do not rewrite this in JS.
- Easing for reveals: `cubic-bezier(0.22, 1, 0.36, 1)`.
- Honor `prefers-reduced-motion`.

### Page patterns that are already approved

- **Video heroes** (home, about, contact): `HeroVideo` with `preload="auto"`, no `poster`. Parent background `#050505`. Video class: `scale-105 object-cover blur-[2px] sm:blur-[3px] brightness-[0.65]`. Overlays: left dark gradient, bottom gradient, content `relative z-10`.

- **Money:** Bangladeshi grouping via `toLocaleString("en-IN")`, prefix `৳` (example `৳ 32,50,000`).
- **Header height:** 68px phone, 80px desktop. Sticky, `z-50`. Mobile drawer stacking is deliberate: overlay `z-40`, drawer `z-60`, nav `z-80`, toggle `z-90`. Do not flatten these.

Short, confident, specific. Showroom in Rajshahi. Japanese reconditioned cars. Auction grades. No hype words, no fake Customs authority, no copied competitor prices. Duty page must say the figure is the staff sheet, not a government assessment, and that the list is separate from live stock.

## 6. Rules that prevent breakage

1. **Admin already exists.** “Build the admin panel” means finish or restyle the current `/admin` routes. Do not add a parallel `/dashboard`, a new auth library, or a second database.
2. **Demo mode must keep working.** Every new read/write needs a path when Supabase env is missing, matching `vehicles.ts` / `leads.ts` / `duty.ts`.
3. **Do not import server-only modules into client components.** No `fs`, no `next/headers`, no `lib/duty.ts` inside `"use client"` files.
4. **Mobile menu stays CSS-first.** The checkbox in `Header.tsx` is the open state. Hydration warnings that mention `data-cursor-ref` come from the Cursor inspector, not from app source. Do not sprinkle `suppressHydrationWarning` across the tree. `body` already has it.
5. **Backdrop blur:** Lightning CSS strips unprefixed `backdrop-filter` from custom CSS. Public header blur uses Tailwind (`backdrop-blur-[64px]`). If you add blur, use Tailwind utilities or include both prefixes and then verify in the browser.
6. **One gold, one wordmark, one phone number.** Match section 4.
7. **Do not copy competitor commercial data** (Gari deposits, Autovan duty PDF, auction-house login).
8. **New public page checklist:** route under `(site)`, header `navLinks`, footer `usefulLinks`, `sitemap.ts`, mobile check, empty and error states.
9. **New admin page checklist:** route under `admin`, link in `admin/layout.tsx`, dashboard card, server action, demo-mode fallback, `revalidatePath` for the public page it affects.
10. **Next.js 16:** read `node_modules/next/dist/docs/` before new APIs. Middleware currently warns that “proxy” is the future convention. Do not migrate that unless asked. It works.
11. **Images:** `next.config.ts` allows any https remote. Prefer existing `Image` usage. Do not tighten remote patterns in a drive-by edit or Supabase storage images break.
12. **LAN dev:** `allowedDevOrigins` in `next.config.ts` lists the phone IP. If the phone’s IP changes, add it. Do not remove localhost.
13. **Git:** commit and push only when the client asks. Never force-push `main`. Never commit `.env.local` or `.data/`.
14. **Verify UI in the browser** after any visual or routing change. Phone width (~390px) and desktop. Click the real control. A screenshot of a closed page is not enough.
